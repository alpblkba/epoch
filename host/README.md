# Host-side tools

`host/client/uart_echo_test.py` performs byte-exact validation of polling and interrupt-driven UART echo firmware. It includes nine deterministic binary vectors, an optional seeded streaming workload, SHA-256 comparisons and a measured mode that reports host-observed timing rather than physical UART line utilization.

`host/client/requirements.txt` pins pySerial, which the experiment runners and their offline tests import. Physical serial tests also require the correct virtual COM port and appropriate permissions; for example, `python3 host/client/uart_echo_test.py --port /dev/cu.usbmodem21303` from the repository root uses a port name specific to one macOS setup.

`host/simulator/` drives the portable controller and host classifier over two lossy links with message loss, duplication, delay, reordering and controller resets, including resets inside cold initialization and optional bit flips in committed slots, and checks every outcome against the retained effect. `host/client/epoch_client.c` is the C host client for the controller firmware and runs the policy reset campaigns. `epoch_wire.py` is an independent Python implementation of the wire codec. `cold_init_trials.py` runs the cold-initialization and inconsistent-pair reset experiments against the reset-injection build, or with `--corrupt` the corrupted-slot experiment against the build that adds `corrupt.conf`, and `retention_probe.py` runs the retention probe. A frame the host rejects during a campaign trial makes that trial inconclusive; `epoch_client` records the count as `rx_errors`. `verify_trials.py` and `verify_cold_init_trials.py` recompute the recorded verdicts without trusting the runner's labels, and the second imports nothing from the other host tools.

The experiment runners reset the board and overwrite its retained state, so run them only on a board set aside for that purpose. The offline tests of every host tool run with `cd host/client && python3 -m unittest test_uart_echo test_epoch_wire test_verify_trials test_retention_probe test_cold_init_trials test_verify_cold_init_trials`.
