# Hardware licence reference

No original EPOCH hardware design sources are included in the initial public release. Future EPOCH-authored RTL, schematics or PCB designs will be released under [CERN Open Hardware Licence Version 2 - Permissive](https://cern-ohl.web.cern.ch/) (`CERN-OHL-P-2.0`) when the specific hardware files are designated under that licence.

CERN maintains the [definitive verbatim text](https://ohwr.org/cern_ohl_p_v2.txt). A future release containing covered hardware designs should include that complete, unmodified text alongside those sources and any required copyright or modification notices. This reference document is not itself a substitute for the licence text.
